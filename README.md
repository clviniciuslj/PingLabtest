# PingLab

- App Android para diagnóstico de rede, feito para quem faz suporte de internet e redes em campo.
- Ping em um ou mais endereços ao mesmo tempo, com latência, perda e quedas em tempo real, num gráfico e num console.
- Traceroute, para ver cada salto até o destino.
- Diagnóstico em etapas, que aponta onde a conexão está falhando.
- Teste de velocidade: download, upload, ping e jitter.
- Favoritos e histórico de endereços.
- Envio dos resultados como texto ou imagem.
